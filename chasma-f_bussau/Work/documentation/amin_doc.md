# Documentation File Template

This file is going to be used as template for the documentation of the project. Copy and paste everything under the
description without erasing your "TO DO" and "DONE" list of the previous days.

Before starting working, fill the "TO DO" list with whatever is in your plans for the day.

After finishing your work, add to your "TO DO" list everything extra that you did, and replace the space between
the "[]" with an "x", as indicated in the template.

Optionally, you can write the TODO list of the next day that you will be working on the project.

At the end push the file to the project, so we are always up-to-date.

## DD/MM/YYYY

### TO DO
- [x] TODO1
- [ ] TODO2
- [ ] TODO3
